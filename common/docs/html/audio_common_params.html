common 參數表 — 外部 / 內部,以及該呼叫的函式

本頁回答兩件事:(1) 第三方可以調的參數有哪些、哪些存在但不建議開放;(2) 整合者實際會呼叫的函式與純內部函式的分界。逐函式簽章見 common API,呼叫順序與時序圖見 common。每列都標出處(audiolib/common/ 底下的檔案)。

分類準則

類別定義
外部描述部署環境(取樣率、FFT 點數、聲道數)或呼叫契約,有界、有驗證,錯值會被拒絕(回 NULL/0)而不是悄悄失效
內部濾波器設計常數、數值護欄、編譯期常數、狀態欄位。存在於程式內、技術上可改,但改動會改變數值結果或破壞與其他 repo 的對位,不建議開放

common 的函式庫物件都沒有執行期 setter:設定在 create/init 時固定,要改就重建物件(並在換串流時才重建,不要逐 block 重建)。

FFT(fft_wrapper.h)

參數類別範圍 / 預設說明與出處
fft_size外部2 的冪、[16, 8192];無預設唯一的 FFT 參數。範圍外 fft_get_mem_size 回 0、fft_create/fft_init 回 NULL(src/fft_wrapper_ne10.c:39)。建立時固定
heap 或 pool 路徑外部fft_create / fft_get_mem_size+fft_initpool 必須 16-byte 對齊;fft_get_mem_size 已含 NE10 內部 cfg 與 twiddle
後端與縮放:NE10、NE10_DSP_RFFT_SCALING、NE10_UNROLL_LEVEL=1、NE10_ENABLE_DSP內部Makefile 固定fft_inverse 的 1/N 完全靠 NE10_DSP_RFFT_SCALING;vendored 後端的 cfg 版面與 UNROLL_LEVEL=1 綁定(Makefile:169、lib/ne10/VENDORED.md)
共用 input staging、scratch、twiddle內部由 fft_get_mem_size 決定同一支 handle 的呼叫不可在時間上重疊;不同 handle 互相獨立(fft_wrapper.h)
fft_power 的 fmaf(re, re, im·im) 運算順序內部—與 NEON 路徑逐 lane 同序,決定位元結果(src/fft_wrapper_ne10.c:198)

STFT / ISTFT / 窗(audio_stft.h、audio_window.h)

參數類別範圍 / 預設說明與出處
fft_size外部2 的冪、[16, 8192];ac_stft_config_default 帶入你給的值hop 固定為 fft_size/2(只支援 50% overlap)(src/audio_stft.c:49)
center外部(AcStft)0 或 1;預設 00 = 每次 push 恆 1 幀;1 = torch.stft(center=True, reflect) 框架(第 1 次 push 0 幀、第 2 次 2 幀)。建立時固定,其他值使 init 回 NULL
ola外部(AcIstft)AC_OLA_ACCUMULATE(預設)/ AC_OLA_ENV_NORMACCUMULATE 每幀吐 hop 個樣本;ENV_NORM 另累加窗平方包絡,第 1 幀不吐樣本,多一張 env[N]
spec_scale / ispec_scale外部float;預設 1.0f;未驗證有限性前向 FFT 後 / 反向 FFT 前對每個 bin 乘的倍率;恰為 1.0f 時略過乘法(bin 為精確搬移)。給 NN 正規化頻譜用
fft / window(借用)外部(進階)NULL = 自帶(預設)借用的 handle 的 n_freqs 必須等於 fft_size/2+1,否則 init 回 NULL;窗表須 fft_size 個 float、不變、活得比物件久;一支 handle 可被多個物件共用,呼叫須循序。省 pool(N=512:21,840 → 6,240 B)
窗公式 sqrtf(0.5f·(1−cosf(2π·k/N)))(週期 sqrt-Hann,float32)內部固定四個 repo 的 WOLA 約定;ac_window_build 的 float 運算順序決定每個係數的捨入(src/audio_window.c)
包絡下限 AC_ENV_FLOOR = 1e-11f內部固定ENV_NORM 的除數下限,對齊 torch.istft 行為(src/audio_stft.c:12)
幀計數飽和(AcStft 3、AcIstft 2)、歷史/暫存陣列內部—決定啟動期的幀數規則,不是調參(src/audio_stft.c:22,36)

HPF(hpf.h)

參數類別範圍 / 預設說明與出處
cutoff_hz外部有限、> 0、嚴格 < 0.45 × sample_rate;無預設16 kHz 上限 7200 Hz。不合法回 NULL(不產生退化係數)(src/hpf.c:37)。AEC 內建的 mic-path HPF 預設 80 Hz(AEC/c_impl/include/aec.h 的 highpass_cutoff_hz),在 AEC 外再串一層前先確認沒有重複
sample_rate外部int,> 0只用來算係數,與 resampler 的 5 個取樣率白名單無關
形式與 Q:二階 Butterworth(係數用 √2)、雙線性轉換、Direct Form II transposed內部固定沒有 Q 或階數參數;改形式等於換濾波器(src/hpf.c:hpf_compute_coeffs)
0.45 的邊界餘裕內部固定讓 tanf(wc/2) 遠離 π/2 的極點(src/hpf.c:35)
狀態 z1, z2內部初值 0hpf_reset 只清這兩個,係數不變。hpf_get_mem_size() = 32 B(本機實測,與 cutoff 無關)

重取樣(audio_resampler.h)

參數類別範圍 / 預設說明與出處
input_rate / output_rate外部8000、16000、24000、32000、48000(可相同)其他值一律被拒;相同 = 精確 memmove 直通(src/audio_resampler.c:rate_supported)
channels外部[1, 8](AUDIO_RESAMPLER_MAX_CHANNELS)介面是交錯 float32
濾波器長度:每側 16 × max(up, down) 個 tap(AUDIO_RESAMPLER_HALF_TAPS_PER_RATIO)內部固定決定延遲與記憶體;延遲 = (filter_length−1)/(2·up) 輸入 frame(src/audio_resampler.c:23,93)
截止 0.47 / max(up, down)(以升頻後取樣率正規化)、Blackman 窗、每個相位列的直流增益正規化到 1內部固定等價於低取樣率奈奎斯特頻率的 0.94 倍。改動會改變通帶/阻帶與所有輸出(src/audio_resampler.c:142-180)
每趟暫存 AUDIO_RESAMPLER_CHUNK = 128 frame內部固定只影響工作區大小;輸出與輸入如何切塊無關(src/audio_resampler.c:26)

pool 與對齊(utility/mem_align.h)

項目類別說明
pool 基底 16-byte 對齊外部(契約)所有 X_init 都檢查,未對齊回 NULL
ALIGN16、MEM_IS_ALIGNED16、MEM_SIZE_INVALID、ck_add_size、ck_mul_size、ck_align16_size、ck_field_size、ck_field_size_reps外部(自己切 pool 時才用)飽和算術;溢位飽和到 SIZE_MAX,走訪結束檢查一次,溢位時 get_mem_size 必須回 0

標頭型核心與編譯期開關

項目類別說明
SIMD_KERNELS_FORCE_SCALAR(消費端 TU 的定義)外部必須與 archive 的 SIMD=0|1 一致:SIMD=0 對應有定義。SK_HAVE_NEON 可在執行期印出確認
-ffp-contract=off -fno-math-errno(消費端 TU)外部include 了 simd_kernels.h/fast_math.h 的 TU 必須帶,放在 CFLAGS 最後
WAV_IO_WRITER_STYLE(wav_io.h)外部(離線工具)WAV_IO_WRITER_AEC(預設)/ WAV_IO_WRITER_NR,須在 include 前定義;AEC 風格另受環境變數 AEC_OUT_FLOAT=1 影響
USE_STANDARD_MATH(fast_math.h)內部(對照用)改用 libm,非有限輸入的結果與近似版不同;selftest 兩種都測
USE_OPTIMIZED_E1(fast_math.h)內部只改 exp1_approx 的分支順序,兩種順序必須逐位元相同(make selftest 兩種都跑)
FM_LOG_C1…C4、exp_int_table、exp1_approx 三段係數(Martin 等 2004 式 (17))內部標頭註明係數不得改動
simd_aec.h、simd_nr.h內部simd_aec.h 是 AEC 專用核心(濾波權重更新 sk_wupdate_*、成對加總、ERLE/ERL 與噪聲追蹤…),simd_nr.h 是 NR 專用核心(環形最小值、增益準備…);由各自 repo 引用與測試

make 變數(建置面)

變數類別說明
SIMD=0|1外部預設 1。0 = 所有可選 SIMD 路徑改走純量(NE10 純量 C 核心)。0 與 1 的 FFT/resampler 輸出只在浮點捨入內一致
EXTRA_CFLAGS、CC/CXX/AR/RANLIB、TOOLCHAIN_CHECK、WERROR外部含 -Ofast、-ffast-math、-ffp-contract=… 的 EXTRA_CFLAGS 在 parse 期被拒;旗標變數只接受由 [A-Za-z0-9_./=,+-] 與空白組成的單純 token(引號等字元也被拒)。交叉編譯時 CC 與 CXX 的 target 必須一致(TOOLCHAIN_CHECK=1)
OBJ_ROOT、BIN_ROOT、DIST_ROOT、make print-lib-path外部archive 路徑由旗標雜湊決定,用 print-lib-path 取得,不要自己拼
BACKEND內部只接受 ne10,其他值建置直接報錯
DEBUG、NO_STDIO內部common 的 Makefile 宣告並納入雜湊,但不消費
ALLOW_DIRTY_PUBLISH、ALLOW_UNTRACKED_PUBLISH、ATTEST_STAMP、HOSTCC內部make publish 的釋出與測試旋鈕
