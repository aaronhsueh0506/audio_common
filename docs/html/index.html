audiolib 音訊函式庫

通用 DSP

FFT、STFT／ISTFT、重取樣和高通濾波使用 libaudio_common.a。從一個 hop 的 C 呼叫開始，查閱輸出緩衝區大小、第一幀和收尾的行為。

空間音訊

呼叫端先對各支麥克風做 FFT。VAD 使用一路頻譜產生遮罩，DOA 和 BF 使用各通道頻譜估計方向並合成波束。此頁附初始化、每 hop 與釋放順序的完整範例。

建置

在 audiolib 根目錄，用 ARM32 或 ARM64 工具鏈執行所需目標。

make -C common lib
make -s -C common print-lib-path

make libspatial_common.a libdoa.a libbf.a libvad.a
make -s print-bin-dir

建置及查詢要使用同一組工具鏈與 SIMD 設定。將空間模組的 archive 放在 libspatial_common.a 之前連結，最後加 -lm。

驗證

make test                       # 空間模組測試，含 audit-no-stdio（四個 archive 不得引用 stdio 符號）
make -C common selftest         # 通用 DSP
make -C common test-full        # 另含 audit-fp-contract 與建置隔離，需要旁邊有 AEC 與 NR checkout

各目標的範圍見 common 建置與驗證。
