DOA / SRP-PHAT(doa/)

對應 audiolib/doa/srp.h、srp.c、doa_smoother.{h,c}。與 VAD、BF 的串接見 空間鏈。

概要

SRP-PHAT 方位角估計:對 M 路麥克風的所有 M(M−1)/2 個麥克風對,先算 PHAT 正規化互功率譜(每個 hop 只算一次,與候選角無關),再對 [0, 2π) 上均勻的 num_angles 個候選角,在搜尋頻帶內累積「互功率譜 × 預先算好的 pair steering」的實部,分數最高的角就是 doa_raw。DOA_Smoother 再把 doa_raw 去抖成 doa_s:新方向要連續出現 switch_consec 次才採用。輸出是弧度;NaN 代表沒有值。

  • 角度與座標:候選角 a 對應 θ = a·2π/num_angles;麥克風位置 (x, y) 以公尺為單位,平面波到第 m 路的延遲 τ = −(x·cosθ + y·sinθ)/c,steering 相位 −2π·f·τ(doa/srp.c:srp_init)。
  • 輸入是頻域:X[m][f](Complex),f 是 bin 序號,freq = f·sr/NFFT。SRP 不做 FFT。
  • 公開 struct SRP 把所有欄位都攤在標頭裡(S_theta、bin_best_idx、pair_steer…),它們是實作細節,不是 API。唯一預期被外部讀取的是 srp->a_array(給 BF 借用,沒有 getter)。

如何呼叫使用

順序:填 ArrayGeometry 與 SRP_Config → srp_get_mem_size(0 = 被拒)→ 16-byte 對齊的 pool → srp_init(NULL = 失敗)→ 每 hop doa_step 再讀 doa_get_smooth/doa_get_raw → srp_reset(換串流)→ srp_destroy。heap 路徑 srp_create_from_geometry(cfg, geom) 內部用 posix_memalign,沒有 POSIX 的目標請用 srp_init。

#include <math.h>
#include "srp.h"

enum { MICS = 4, BINS = 129 };                       /* 16 kHz、NFFT 256 */
static unsigned char g_srp_pool[800 * 1024] __attribute__((aligned(16)));   /* >= srp_get_mem_size(&cfg) */

SRP *doa_open(float *mic_x, float *mic_y)            /* 麥克風位置(公尺) */
{
    ArrayGeometry geom = { MICS, mic_x, mic_y };
    SRP_Config cfg = {0};
    cfg.M = MICS; cfg.F = BINS; cfg.num_angles = 72;  /* 5 度一格,角度 0..2π */
    cfg.sr = 16000.0f; cfg.NFFT = 256.0f; cfg.c = 343.0f;
    cfg.low_freq = 300.0f; cfg.high_freq = 7000.0f;
    cfg.enable_smoothing = 1; cfg.switch_consec = 3;
    cfg.angle_tol = 10.0f * 3.14159265f / 180.0f; cfg.update_interval = 2;

    size_t bytes = srp_get_mem_size(&cfg);            /* 0 = 設定被拒 */
    if (bytes == 0 || bytes > sizeof g_srp_pool) return NULL;
    return srp_init(g_srp_pool, bytes, &cfg, &geom);  /* NULL = geom 不符、未對齊或 pool 太小 */
}

/* 每 hop:X[m] 是第 m 路的 BINS 個頻譜 bin。回傳平滑後的方位角(弧度),NaN = 還沒有 */
float doa_hop(SRP *s, const Complex *const *X, const int *mask, int vad_raw, int vad_out)
{
    doa_step(s, X, mask, vad_raw, vad_out);           /* vad_raw 為 1 且輪到時才真的跑 SRP */
    /* doa_get_raw(s):本 hop 的原始結果,沒跑 SRP 的 hop 為 NaN */
    return doa_get_smooth(s);                         /* 換向有 switch_consec 次確認,期間維持舊值 */
}
/* 換串流:srp_reset(s);結束:srp_destroy(s)(pool 路徑不釋放記憶體) */
函式什麼時候呼叫失敗/邊界
srp_get_mem_size(cfg)init 前一次0 = M<=1、F<=1、num_angles<=0,或 sr/NFFT/c 非有限或 <=0,或 low_freq/high_freq 非有限(srp.c:38);此函式拿不到 geom,所以不檢查幾何
srp_init(mem, n, cfg, geom)一次NULL = 上述設定不合法、geom->M != cfg->M、geom->x/y 為 NULL、mem 未 16-byte 對齊、n 不足(srp.c:49,110)。geom 只在 init 內被讀取
doa_step(s, X, mask, vad_raw, vad_out)每 hop 一次s 或 X 為 NULL 靜默返回。mask 可為 NULL(全部 bin);非 0 表示「該 bin 計入分數」
doa_get_smooth(s) / doa_get_raw(s)doa_step 之後NULL 或尚無值回 NaN
srp_reset(s)換串流、重新開始追蹤清 frame_counter、DOA、smoother;steering 表不動
srp_destroy(s)結束pool 路徑不釋放;heap 路徑釋放整塊;BF 須先銷毀

低階入口(一般不需要):srp(s, X, mask) 只算分數(填 S_theta)、srp2doa(s) 取分數最高的角,兩者不做 NULL 檢查,也不經 update_interval 與 smoother;doa_smoother_update 是 doa_step 內部用的去抖函式。

情況doa_rawdoa_s
vad_raw = 0,或這個 hop 不是 update_interval 的倍數NaN上一個有效值(從未有過則 NaN)
跑了 SRP,enable_smoothing = 1,vad_out = 0新值維持上一個有效值
跑了 SRP,enable_smoothing = 1,vad_out = 1新值smoother 輸出(首次直接採用;換向要連續 switch_consec 次)
跑了 SRP,enable_smoothing = 0新值等於 doa_raw(不看 vad_out)

swimlane(換向需要幾個 hop)見 空間鏈。SRP 本身不引入取樣延遲;doa_s 換向需要 switch_consec 次連續的 SRP 觀測,即第一次觀測到新方向後再經 (switch_consec−1) × update_interval hop(vad_raw 持續為 1 時)。

參數表

分類沿用 AEC/NR 參數面整理的準則:外部 = 第三方可決定、有界、效果可預期;衍生 = 由陣列與 FFT 格點決定,不是調參;內部 = 存在於程式內、技術上可改,但不建議開放。「sample beam」欄是專案內唯一整合者(sample beam helper)的 mcab_sample_beam_default_params()(Audio_ALG/pipelines/4ch_aec_bf_nr_res/mcab_sample_beam.c)使用的值,僅供參考。所有 SRP_Config 欄位都是建立時固定。

外部(SRP_Config 與 ArrayGeometry)

欄位單位/範圍(程式碼驗證)作用與取捨sample beam
ArrayGeometry.x/y[m]公尺;M 筆,非 NULL由硬體決定。座標軸定義了「0 弧度」的方向;BF 借用 SRP 的 steering 表,不另外收幾何UCA 半徑 0.035 m
num_angles> 0;解析度 = 360/num_angles 度記憶體與每 hop 算量都近似線性成長(pair_steer 與 a_array);BF 必須用同一個值72(5°)
low_freq / high_freqHz,有限;轉成 bin round(f·NFFT/sr),f_start 夾在 [1, F−1],f_end 夾在 [f_start, F−1]搜尋頻帶。太低受低頻雜訊與孔徑限制,太高受空間混疊;高於 Nyquist 自動夾限300 / 7000

衍生(要填,但不是調參)

欄位規則
M必須 >1 且等於 geom->M;BF 與 X 的路數必須相同
F必須 >1;程式不檢查 F == NFFT/2+1,不符時 X[m] 的長度必須至少是 F,否則越界

狀態與記憶體

SRP 的狀態全部在 caller 的 pool 內(單一區塊,srp_init 先清零再切分,切分後必須剛好用完)。srp_reset 清追蹤狀態但不重算 steering 表。實測大小見 空間鏈 的記憶體表(A=72、M=4、F=129:758,608 B;ARM64/LP64 量測)。
