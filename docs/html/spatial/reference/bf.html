波束器 BF(bf/)

對應 audiolib/bf/bf.h、bf.c。與 SRP、VAD 的串接見 空間鏈。

概要

頻域自適應波束器,結構是 GSC 形式:固定波束 das(以目前方向的 steering 做共軛加權平均,係數 1/M)減去自適應分支 waH·u,其中 u = x − a·(aHx)/(aHa) 是把目標方向投影掉的 blocking 輸出。wa 以逐 bin 的 RLS 更新。方向來自呼叫端傳入的 doa_s(通常是 SRP 的 doa_get_smooth),BF 自己不做 DOA、也不做任何保持(hold);也可以設定固定波束。

  • 輸入 X[m][f] 是 M 路、F 個 bin 的頻譜;輸出 bf_out[F] 是波束後頻譜(Complex)。BF 不做 FFT/OLA,時域重建由整合者負責。
  • steering 表是借用的:a_array[angle][mic][bin] 由呼叫端擁有(通常是 srp->a_array),bf_init 不複製、bf_destroy 不釋放。BF 用 doa2index 把方向四捨五入到 360/num_angles 度的格點,所以 num_angles 必須與產生這張表的格點一致;非有限的方向取 0 號格點(bf.c:doa2index)。
  • 遮罩極性與 SRP 相反:BF 的 mask 非 0 表示「凍結該 bin 的 RLS 更新」(fixed_align_notebook 模式例外,該模式忽略遮罩)。

如何呼叫使用

順序:取得 steering 表 → bf_get_mem_size(M, F)(0 = M 或 F 不合法;大小與 num_angles、cfg 無關)→ 16-byte 對齊 pool → bf_init(NULL = 失敗)→ 每 hop bf_process_with_weights(不要權重時 w 傳 NULL)→ bf_reset(換串流)→ bf_destroy(要在擁有 steering 表的 SRP 之前)。heap 路徑 bf_create(M, F, num_angles, a_array, cfg) 內部用 posix_memalign。

#include "bf.h"

enum { MICS = 4, BINS = 129, ANGLES = 72 };
static unsigned char g_bf_pool[32 * 1024] __attribute__((aligned(16)));   /* >= bf_get_mem_size(MICS, BINS) */

/* a_array[angle][mic][bin]:steering 表,由呼叫端擁有(例如 srp->a_array),BF 只借用、不複製也不釋放。
 * num_angles 必須與產生這張表的格點相同。fixed_doa_rad 只在 fixed_mode = 1 時使用。 */
BF *beam_open(Complex ***a_array, int fixed_mode, float fixed_doa_rad)
{
    BF_Config cfg = {0};
    cfg.enable = 1;                    /* 0 = 直通第 0 路 */
    cfg.lambda = 0.995f;               /* RLS 遺忘因子,(0, 1],單位是「每次更新」 */
    cfg.mu = 0.1f;                     /* 權重更新步長倍率 */
    cfg.adapt_interval = 1;            /* 每 N 個 frame 才做一次 RLS 更新;輸出每個 frame 都算 */
    cfg.enable_fix_mode = fixed_mode;  /* 1 = 波束固定指向 fixed_doa_rad,忽略傳入的 doa_s */
    cfg.fixed_doa_rad = fixed_doa_rad;
    size_t bytes = bf_get_mem_size(MICS, BINS);          /* 與 num_angles、cfg 無關;0 = M 或 F 不合法 */
    if (bytes == 0 || bytes > sizeof g_bf_pool) return NULL;
    return bf_init(g_bf_pool, bytes, MICS, BINS, ANGLES, a_array, &cfg);   /* NULL = lambda/mu/doa 不合法等 */
}

/* 每 hop:X[m] 為第 m 路的 BINS 個 bin;doa_s 為 NaN(尚無方向)時輸出 = X[0],且不更新 */
void beam_hop(BF *bf, const Complex *const *X, float doa_s, int vad_out, const int *mask, Complex *beam)
{
    /* allow_adapt:通常只在「沒有目標語音」(vad_out == 0)時讓 RLS 學;mask 非 0 的 bin 不更新 */
    bf_process_with_weights(bf, X, doa_s, vad_out ? 0 : 1, mask, beam, NULL);
    /* bf_get_adaptive(bf):本 hop 是否真的做了 RLS 更新;bf_get_doa_used(bf):實際使用的方向 */
}
/* 換串流:bf_reset(bf)(清 RLS 與計數,bin_resets 不清);結束:bf_destroy(bf) */
函式失敗/邊界
bf_init(mem, n, M, F, num_angles, a_array, cfg)NULL = mem/cfg/a_array 為 NULL、M/F/num_angles <= 0、lambda 非有限或不在 (0, 1]、mu 非有限、固定模式下 fixed_doa_rad 非有限、mem 未對齊或 n 不足(bf.c:bf_init 開頭的檢查)。init 只清 bf_get_mem_size 的範圍
bf_process_with_weights(g, X, doa_s, allow_adapt, mask, bf_out, w)不檢查 NULL;X 必須是 M 個各含 F 個 bin 的指標;bf_out 要 F 個 Complex;另外把本 hop 更新前的等效權重寫進 w[M*F](通道主序,w[m*F+f]);bf_out[f] = Σ_m w[m,f]·X[m,f](呼叫端不必再取共軛)。w 可為 NULL,bf_out 必須有
bf_get_doa_used(g) / bf_get_adaptive(g)NULL 回 NaN / 0。bypass 的 hop 兩者為 NaN / 0
bf_effective_adapt_interval(fix, notebook, interval)BF 實際使用的更新間隔(interval <= 0 為 1;固定+notebook 強制 1)。要依更新節奏推算時間常數的整合者必須用它,而不是自己的設定值

     |                     |  frame_idx++

BF 沒有取樣延遲(同 hop 輸入、同 hop 輸出)。RLS 的收斂速度由 lambda 與更新次數決定,更新次數 = 滿足 allow_adapt、adapt_interval、遮罩三道門的 hop 數;swimlane 見 空間鏈。

參數表

分類準則同 DOA/SRP。BF 沒有任何執行期 setter,所有設定在 bf_init 時固定。「sample beam」欄是專案內 sample helper 的 array_sample_beam_default_params()(Audio_ALG/pipelines/4ch/array_sample_beam.c)使用的值,僅供參考。

外部(BF_Config)

內部(不建議開放)

項目位置為什麼不開放
fixed_align_notebook(BF_Config 欄位,但屬內部)bf.c:bf_effective_adapt_interval、bf_process_with_weights_impl、bf_rls_update_bin_scalar為了對齊參考實作而存在:強制每 frame 更新、停用遮罩凍結與 mu、upu 多加一個 lambda。只在固定模式下有意義,不是產品選項
BF_WA_LEAK = 0.99999fbf.c:18;唯讀 bf_wa_leak_factor()只在實際更新時套用的權重漏洩,時間常數 1/(1−leak) 次更新,遠慢於遺忘時間,用來限制長時間連續執行的 wa 成長;與 lambda 耦合
BF_P_DIAG_FLOOR = 1e-6f、BF_P_DIAG_CEIL = 1e6fbf.c:25-26;唯讀 bf_p_diag_floor/ceil()RLS 發散護欄,每次更新後夾 P 的對角。改動會悄悄改變 bin_resets 的觸發行為
upu 守衛:非有限或 <= 0 重置該 bin;|upu| < 1e-12f 墊到 1e-12fbf.c:bf_rls_update_bin_scalar(NEON 路徑 bf_rls_update_four_neon 同規則)單 bin 重置而非整個 BF 重置,避免丟掉其他 bin 的適應;屬數值護欄
投影分母下限 1e-12f、das 係數 1/M、P 的 Hermitian 對稱化common/utility/spatial_simd.c:162、bf.c演算法定義的一部分;scalar/NEON 共用
